# Yandex Music Liberty Mod

Этот форк основан на оригинальных модах (YandexMusicBetaMod), но включает в себя **полностью независимую систему обхода цензуры (YM Liberty)** с собственной базой треков и ботом для заявок.

![Скриншот приложения](./docs/preview-5.117.1.png)

## 🚀 Что добавлено и исправлено

- **Независимая база без цензуры (YM Liberty)**: Автоматическая замена заглушенных треков на оригинальные (без цензуры). База полностью отвязана от старых серверов и работает через Github + Hugging Face.
- **Интеграция с Telegram**: Заявки на отсутствующие треки отправляются напрямую боту администратора через кнопку в приложении.
- **Авто-обновление базы**: Мод подтягивает свежие треки каждые 30 секунд. Перезагрузка приложения после добавления нового трека больше не требуется!
- **Discord Rich Presence**: Отображение текущего трека в Discord.
- **Кастомные темы**: Выбор любых цветов (включая градиенты HEX) в настройках мода.
- **Исправление ошибок (405 Error)**: Исправлена ошибка скачивания обновлений.
- **Вырезаны лишние логи**: Удалены ошибки 404 при загрузке локальных модулей Яндекс Музыки.
- **Скачивание музыки**: Загрузка треков в форматах MP3 и FLAC.
- **Доступ к DevTools**: Встроенная консоль разработчика по нажатию F12.

## 📥 Как установить

Готовый инсталлятор со вшитым модом находится в разделе **[Releases](https://github.com/gagayhhad-tech/YandexMusicBetaMod-FckCensor/releases)** на GitHub. Просто скачайте `.exe` файл и установите (официальный клиент отдельно качать не нужно, он уже внутри).

## 🛠 Сборка из исходников

Если вы хотите собрать установщик самостоятельно:

1. Установите [Bun](https://bun.sh/).
2. Откройте терминал в папке с клонированным репозиторием и выполните:
   ```bash
   bun install
   ```
3. Запустите сборку:
   ```bash
   bun start
   ```
