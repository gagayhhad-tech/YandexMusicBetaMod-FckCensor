# 🎵 Яндекс Музыка — FckCensor Edition

Этот форк объединяет лучшее из двух миров: актуальную базу [YandexMusicBetaMod от HoleverGG](https://github.com/HoleverGG/YandexMusicBetaMod) (в свою очередь форк [Stephanzion](https://github.com/Stephanzion/YandexMusicBetaMod)) и скрипт обхода цензуры **[FckCensor от Hazzz895](https://github.com/Hazzz895/FckCensor)**. 

В данной сборке анти-цензура встроена **нативно, без возможности отключения и без необходимости в ручных манипуляциях** (никаких скриптов для Tampermonkey не требуется).

![Интерфейс Яндекс Музыки](./docs/preview-5.112.0.png)

> [!IMPORTANT]
> Мод основан на последних версиях оригинальных репозиториев и стабильно работает с новейшим движком Яндекс Музыки (Next.js).

## ✨ Главные возможности

- **Встроенный обход цензуры**: Автоматическая подмена заблокированных и зацензуренных треков (нативная интеграция аддона FckCensor). Треки подгружаются из локальной базы и облачного репозитория сообщества.
- Интеграция с Discord Rich Presence
- Отключение рекламы и аналитики
- Выбор высокого качества воспроизведения
- Загрузка треков в MP3 и FLAC
- Пользовательские темы, шрифты и масштаб интерфейса
- Режим разработчика (DevTools)
- Дополнительное меню настроек мода

## 🆕 Что было изменено в этом форке

- **Интеграция FckCensor**: Мод глубоко встроен в загрузчик приложения (через перехват `webpackChunk_N_E`). Решена проблема гонки состояний (Race Condition) — скрипт дожидается инициализации движка приложения, поэтому работает стабильно даже после холодных перезапусков.
- **Скачивание оригиналов без цензуры**: Встроенный загрузчик треков теперь интегрирован с базой FckCensor. При скачивании треков мод автоматически проверяет наличие замены и скачивает незацензуренный MP3/FLAC оригинал вместо версии Яндекса!
- **Произвольные цвета и шрифты**: В отличие от оригинальных форков с зашитыми пресетами, здесь добавлена поддержка выбора *абсолютно любого* HEX-цвета (через нативную палитру) и ввода названия *любого* системного шрифта для интерфейса плеера.
- **Исправление сборки (405 Error)**: Устранен баг оригинального репозитория при обращении к S3-серверам Яндекса (`latest.yml`). Запросы переведены с библиотеки `axios` на нативный `fetch`, что предотвращает блокировку со стороны WAF Яндекса.
- **Восстановление приватных пакетов**: Исправлена ошибка сборки, при которой пакетный менеджер падал (404) из-за попытки скачать недоступные внутренние зависимости (`@yandex-music-int/*`). Теперь они корректно сохраняются и возвращаются на место перед сборкой через `electron-builder`.

## 💻 Установка

*Если вы хотите просто пользоваться приложением, скачайте готовый установщик со страницы Releases (если доступен).*

Если вы хотите собрать приложение самостоятельно из исходников:

1. Установите [Bun](https://bun.sh/).
2. Откройте терминал в папке проекта и выполните установку зависимостей:
   ```bash
   bun install
   ```
3. Запустите патчер (он сам скачает свежую версию Музыки с серверов Яндекса, пропатчит её и соберёт установщик):
   ```bash
   bun start
   ```
